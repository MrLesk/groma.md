## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
GitHub issue #141 requests MQL5 support so a developer can inspect that source in Groma without installing its project dependencies or development toolchain. The user requested an implementation agent for each scanner, a cold simplicity review, then independent adversarial validation on 3-5 public repositories. Existing scanner contracts own evidence; core owns C4 boundaries and OKF output. Publication and merging are separate from preparing and qualifying these scanners.

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Package the pinned ISC MQL5 Tree-sitter grammar and its recorded source patch as WASM with bundled web-tree-sitter 0.27.1 and licenses. Normal builds copy assets. Scans read only Groma-selected .mq5/.mqh/.h files without language tools, project execution or network; only .mq5 signals discovery.
2. Keep five concrete owners: index coordinates the contract; syntax owns selected reads and parser trees; preprocessing records bounded selected-definition macro spans and scope evidence; declarations owns literal names/access/outlines; evidence owns operations, unresolved calls, diagnostics and proven own-file entries. Core retains existing OKF/C4 semantics.
3. Preserve every source position and raw conditional alternative. Same-width placeholders never supply a declaration, name, type, visibility, call or entry. Omit dependent headers/statements, macro-replaced callable/type names and macro argument calls. Unknown unsupported syntax fails; no expansion, flag choice or generic recovery.
4. Use directly balanced replacement tokens to bound scope escape through selected definitions. Unsafe references, uncertain arguments, cycles, two-formal pastes and unknown token forms stay unbounded. One-formal paste chains with fixed identifier prefix/suffix require every matching selected macro name to have contained scope, including empty arguments and every alternative. Withhold unproven body callers and later type owners, while preserving literal earlier members and the one-method-scope sibling control. Opaque access remains unknown until a written access label; that label cannot restore an unknown owner.
5. Prove event names/signatures and own-file membership. Unrelated VERSION metadata does not hide PositionSizer OnTick; conditional/property/signature uncertainty, competing hidden handlers and opaque global declarations still suppress entries. Preserve ordinary constant arguments and independent literal calls.
6. Keep the grammar patch narrow and source-backed: ordinary MQL forms, raw conditional fragments, documented opaque event maps, observed continued-comment directives and complete quoted directive tokens, apostrophes inside real trailing comments and block comments before continuations. Run the unchanged upstream corpus. Focused concurrent regressions cover the independently reproduced syntax/owner/caller and physical-position defects, with recorded before-fail evidence and invalid/unknown controls.
7. Preserve the unchanged six pinned full selections, exact source hashes and independent source-backed expectations. Compare operations, calls, outlines and own-file entries, record restored and withheld evidence, and keep macro-generated architecture explicitly unknown. Freeze separate portable packages and exercise offline/no-tools scans plus the isolated fresh consumer.
8. Complete cold simplicity, implementer specification/quality, final full-context complexity and independent pinned-repository qualification. Integrate the frozen package above shared plugin changes, confirm matching runtime hashes, and pass the combined repository check before finalizing the local implementation.
