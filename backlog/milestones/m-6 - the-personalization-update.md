## Description

Let people choose how Groma looks and which architecture they focus on.

Deliver seven primitives: cloneable UI theme plugins configured in config.json; authored icons; authored element and group colors; standard OKF tags; web filtering that dims nonmatching architecture; exports selected with includeFilter and excludeFilter; and remembered, shareable theme and filter choices.

UI themes own interface surfaces, background, text, grid, and controls. Authored icons and colors belong to the architecture and remain independent of the selected UI theme. Tags use OKF 0.2 top-level tags; Groma-specific presentation metadata stays under groma. Systems, containers, and components keep their C4 meaning; groups remain narrative overlays without adding a containment level.

Start from current main. The partially failed personalization PoC is research material, not accepted implementation or completed work. Keep the existing configuration and map-view owners where they fit. Activity metrics, assigned-work filters, criticality review, and marketplace distribution are outside this milestone.
